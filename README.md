# პადელის სკოლა — საიტი

ეს არის მზა სტატიკური საიტი. სერვერი და პროგრამირება არ სჭირდება: საკმარისია `index.html`-ის გახსნა ბრაუზერში.

## საქაღალდეები

| ფაილი | რა არის |
|---|---|
| `index.html` | საიტის მთავარი გვერდი |
| `data/lessons.js` | **ყველა კურსი და გაკვეთილი** — აქ ამატებ ვიდეოებს და ცვლი ტექსტებს |
| `assets/style.css` | დიზაინი (ფერები, შრიფტები) |
| `assets/app.js` | საიტის ლოგიკა (ამას შეხება არ სჭირდება) |
| `videos/` | საკუთარი ვიდეო ფაილებისთვის (თუ YouTube-ს არ იყენებ) |

## როგორ დავამატო ვიდეო

1. ატვირთე ვიდეო YouTube-ზე (შეგიძლია „Unlisted“ / „შეზღუდული წვდომით“) ან Vimeo-ზე.
2. გახსენი `data/lessons.js` ნებისმიერ ტექსტურ რედაქტორში.
3. იპოვე საჭირო გაკვეთილი (მაგ. `id: "b01"` — ფორეჰენდი).
4. `video: ""` შეცვალე ბმულით:

```js
{ id: "b01", title: "ფორეჰენდი", minutes: 10, video: "https://www.youtube.com/watch?v=XXXXXXXXXXX",
```

5. შეინახე ფაილი და განაახლე გვერდი. ვიდეო გამოჩნდება, ხოლო გაკვეთილების სიაში „მალე“ შეიცვლება „ვიდეო“-თი.

საკუთარი ფაილისთვის ჩადე ვიდეო `videos/` საქაღალდეში და ჩაწერე `video: "videos/b01.mp4"`.

## უფასო და ფასიანი გაკვეთილები

`free: true` გაკვეთილი ყველასთვის ღიაა, დანარჩენი ჩაკეტილია გამოწერამდე (10 ₾ თვეში). ფასი და ბანკის გადახდის ბმული იცვლება `data/lessons.js`-ის `subscription` ნაწილში. საიტის გაშვებამდე ჩაწერე `demo: false`. ნამდვილი გადახდისთვის საჭიროა ბანკის ონლაინ გადახდა და ანგარიშების სისტემა (იხ. გადაღების გზამკვლევი).

## როგორ დავამატო ან შევცვალო გაკვეთილი

`data/lessons.js`-ში დააკოპირე ნებისმიერი გაკვეთილის ბლოკი `{ id: ... }`-დან `}`-მდე, ჩასვი სასურველ ადგილას და შეცვალე:
- `id` — უნიკალური მოკლე კოდი (მაგ. `"b12"`)
- `title` — სათაური
- `minutes` — ხანგრძლივობა წუთებში
- `summary` — მოკლე აღწერა
- `points` — 3 მთავარი პუნქტი

ფაილის თავში `name`, `tagline` და `contact` ცვლის სკოლის სახელს და ქვედა ზოლის ტექსტს.

## როგორ გამოვაქვეყნო ინტერნეტში (უფასოდ)

- **Netlify Drop**: გადადი app.netlify.com/drop-ზე და ჩააგდე მთელი `padel-school` საქაღალდე.
- **GitHub Pages** ან **Cloudflare Pages** — იგივე ფაილები, საკუთარი დომენით (მაგ. padel.ge).

## შენიშვნა

„გავლილი“ გაკვეთილების მონიშვნა ინახება მომხმარებლის ბრაუზერში. მომავალში, თუ გინდა რეგისტრაცია, გადახდა ან ფასიანი კურსები, საიტი შეიძლება გადავიტანოთ სასწავლო პლატფორმაზე ან დავამატოთ ანგარიშები.
